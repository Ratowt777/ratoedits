# Design & Edits Hub

Crie uma Landing Page moderna, responsiva, jovem e interativa para um portfólio e venda de serviços de Design Gráfico (Canva, cartazes, etc.), Edição de Vídeo (Edits) e Criação de Sites.



ESTILO E INTERATIVIDADE (EFEITO HOVER / TOUCH):

- Visual em Dark Mode elegante (fundo escuro tipo #0f172a com destaques em roxo neon ou azul ciano).

- Adicione efeitos de transição suave e micro-interações: quando o usuário passar o cursor (no PC) ou o dedo (no celular) por cima dos cartões de serviços, botões e imagens do portfólio, os elementos devem flutuar e mover levemente para cima (translateY -5px ou -8px) e aumentar o brilho/sombra (glow effect).
